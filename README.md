## Projects

### CaterMatch
A two-sided marketplace that connects food trucks and mobile caterers with the people hosting events. Think Craigslist, rebuilt for the food-truck economy. Vendors post "service available" listings, hosts post event gigs, and one toggle flips the whole browse experience between the two sides.

Built with React, Vite, Tailwind, Socket.io for real-time chat, Express, PostgreSQL with PostGIS for location search, and Stripe for payments.

[Repo](https://github.com/sebastiancapraru1x-rgb/CaterMatch)

### CleatFarm
An online store for football boots, plus a private dashboard for managing inventory and orders. The interesting part isn't the shop — it's the automated pipeline that pulls a supplier's catalog into the store every day with no manual upkeep.

Built to run serverless on Cloudflare Workers (Hono + D1), with a Node/Express fallback. Includes a full test suite.

[Repo](https://github.com/sebastiancapraru1x-rgb/CleatFarm)
